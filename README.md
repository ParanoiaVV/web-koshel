# BOOKLAB — практические задания

Учебный проект по Git/GitHub, HTML5, JavaScript, `fetch()` и использованию ИИ. Страница показывает книжную полку и загружает данные из опубликованной Google Таблицы.

## Ссылки

- Сайт GitHub Pages: будет добавлена после включения Pages.
- Репозиторий: https://github.com/ParanoiaVV/booklab-practice
- Google Таблица (CSV): будет добавлена после публикации таблицы.
- Pull Request: будет добавлен после создания PR.

## Запуск

Откройте `index.html` через GitHub Pages или локальный сервер. Кнопка «Открыть полку» пишет `Кнопка нажата` в консоль и прокручивает страницу к данным. `script.js` использует `fetch()` для загрузки CSV, проверяет HTTP-ответ и показывает сообщение при ошибке.

## Структура

- `index.html` — корректная HTML5-разметка, заголовок, текст, кнопка и картинка с `alt`.
- `script.js` — click-событие, изменение текста, загрузка и отображение данных.
- `style.css` — адаптивное оформление.
- `images/reading.svg` — локальная иллюстрация для стабильной работы сайта.
- `ai-report.md` — промпт, краткая копия ответа ИИ, ручная проверка и рефлексия.

## Google Таблица

Таблица содержит колонки `title,author,year` и четыре строки: «Маленький принц», «Атомные привычки», «451° по Фаренгейту», «Норвежский лес». После публикации CSV-ссылка указывается в `script.js` в константе `GOOGLE_CSV_URL`.
